# 自己学習リポジトリ

45歳FIRE(年間投資470万円)達成のための市場価値向上KPI(Track B③)の実行エンジン。年収900万円水準のデータサイエンティスト/AIエンジニアに求められるスキルを、優先順位付けした上で計画的に習得し、成果物として公開していく。

## 全体の流れ

1. 市場調査でスキルギャップを特定(親フォルダの `02_スキルシート.md`)
2. 重要度・習得難易度・汎用性の3軸で優先度スコアを算出(`07_スキル優先順位バックログ.md`)
3. バックログ上位から2〜4スキルを組み合わせて成果物テーマを選定(`04_成果物管理.md` のプロジェクト憲章)
4. テーマを構成する各要素スキルについて、着手前に学習計画・ミニ成果物の合格基準を定義(`skills/<スキル名>/00_学習計画.md`)
5. 各スキルのミニ成果物を実装し、PRで提出 → レビュー(合格/不合格判定)
6. 全要素スキルが合格したら、複合成果物(テーマ本体)を実装し、PRで提出 → レビュー
7. 合格したら親フォルダの `02_スキルシート.md`(レベル更新)・`03_証明ポイント記録.md`(OSS公開分の加点)・`04_成果物管理.md`(完了記録)に反映

詳細な設計は親フォルダの `01_KPI設計.md` を参照。

## フォルダ構成

```
自己学習/
  00_学習ロードマップ.md   … 現在選定中のテーマと進捗状況の索引
  skills/<スキル名>/       … 要素スキルごとのミニ成果物
  projects/<テーマ名>/     … 複合成果物(テーマ本体)
```

## 提出・評価ルール

- 各成果物は着手前に合格基準を定義し、後出しで変更しない
- ブランチを切ってPRを作成し、レビューを受ける
- レビュー結果は各フォルダの `評価ログ.md` に記録する
