## 進め方(チュートリアル)

### 1. Airflow公式の docker-compose を取得する

このフォルダ(`skills/データパイプライン構築/`)で以下を実行します(公式ドキュメントのクイックスタート手順)。

```bash
curl -LfO 'https://airflow.apache.org/docs/apache-airflow/2.9.3/docker-compose.yaml'
mkdir -p ./dags ./logs ./plugins ./config ./data
echo -e "AIRFLOW_UID=50000" > .env
```

Windows(PowerShell)の場合は `AIRFLOW_UID=50000` を `.env` ファイルに直接書き込んでください。

初期化と起動。

```bash
docker compose up airflow-init
docker compose up -d
```

数分待って `http://localhost:8080` を開くと、Airflowのログイン画面が出ます(初期ユーザー: airflow / airflow)。

### 2. DB設計のPostgresと同じネットワークに繋ぐ

`skills/DB設計/` で立てたPostgresコンテナに、このAirflowコンテナからアクセスできるようにします。一番簡単なのは、`docker-compose.yaml` の `networks` 設定を共有するか、Airflow側のタスクからDB設計側のコンテナ名を直接指定する方法です。両方のdocker-composeを同じ `docker network` に参加させる場合の例:

```bash
docker network create study-net
```

DB設計側・Airflow側それぞれの `docker-compose.yml`/`docker-compose.yaml` に以下を追記して、両方を同じネットワークに参加させます。

```yaml
networks:
  default:
    external:
      name: study-net
```

うまく繋がらない場合は、両方を1つの`docker-compose.yml`にまとめる方法もあります(構成に詰まったら相談してください)。

### 3. サンプルCSVを用意する

`./data/new_orders.csv` を作成します。

```csv
customer_id,order_date,status
1,2026-02-01,completed
2,2026-02-02,completed
1,2026-02-03,pending
```

### 4. DAGを作成する

`./dags/retail_orders_etl.py` を作成します。

```python
from datetime import datetime, timedelta
import csv

import psycopg2
from airflow import DAG
from airflow.operators.python import PythonOperator

default_args = {
    "retries": 3,
    "retry_delay": timedelta(minutes=2),
}


def load_orders_csv():
    conn = psycopg2.connect(
        host="study-db-design",  # DB設計側コンテナのコンテナ名
        port=5432,
        dbname="retail",
        user="study",
        password="study",
    )
    cur = conn.cursor()
    with open("/opt/airflow/data/new_orders.csv", newline="", encoding="utf-8") as f:
        reader = csv.DictReader(f)
        for row in reader:
            cur.execute(
                "INSERT INTO orders (customer_id, order_date, status) VALUES (%s, %s, %s)",
                (row["customer_id"], row["order_date"], row["status"]),
            )
    conn.commit()
    cur.close()
    conn.close()


with DAG(
    dag_id="retail_orders_etl",
    start_date=datetime(2026, 1, 1),
    schedule_interval="@daily",
    catchup=False,
    default_args=default_args,
) as dag:
    load_task = PythonOperator(
        task_id="load_orders_csv",
        python_callable=load_orders_csv,
    )
```

`psycopg2`がAirflowのイメージに入っていない場合は、`_PIP_ADDITIONAL_REQUIREMENTS: psycopg2-binary` を`docker-compose.yaml`の環境変数に追加するか、`requirements.txt`を使ったカスタムイメージを作ってください。

### 5. 実行して確認する

`http://localhost:8080` を開き、DAG一覧から `retail_orders_etl` を探してトグルをON(有効化)にします。右側の再生ボタン(Trigger DAG)で手動実行します。

- Graph view でタスクが緑色(success)になっているか確認
- タスクをクリックして「Logs」タブでログを確認
- `docker compose exec postgres psql -U study -d retail -c "SELECT * FROM orders ORDER BY order_id DESC LIMIT 5;"` でデータが入っているか確認

### 6. リトライ・エラーハンドリングの確認

上記コードにはすでに `default_args` で `retries: 3`, `retry_delay: timedelta(minutes=2)` を設定しています。これはタスクが失敗した場合に2分間隔で最大3回リトライする設定です。わざと存在しないファイルパスを指定してタスクを失敗させ、Graph viewでリトライの様子(タスクが黄色→再試行)が見えることを確認し、スクリーンショットを撮っておいてください。
